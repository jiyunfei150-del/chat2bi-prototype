章节

    看板存在哪、怎么回看

    存的是“怎么取数”，不是数本身

    一块看板 = 布局、全局筛选、版本号，加上若干卡片。每张卡片存参数化 SQL 骨架、参数、图表设置和来源（哪个会话、哪一轮）。落在 brain-query 自己的存储里，按项目和所有者归属，不另起一套库。

    打开就是最新的数

    左侧「智能看板」进入看板列表：我的看板、共享给我的。打开时按当前参数重新执行每张卡片的 SQL，结果按 SQL 指纹加参数做短期缓存，同一时段多人打开不会重复打数仓。

    想看“当时的数”，看快照

    每次推送、每份生成的文档都带当时的数字快照，在订阅推送日志和文档里能找到。看板本身每次改动记一个版本，历史版本可以查看和回放；回放展示的是看板怎么变过来的，数字仍按当前口径重算。
